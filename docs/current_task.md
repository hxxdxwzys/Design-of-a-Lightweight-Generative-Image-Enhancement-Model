- rc=0但缺终态成功标记 → FAIL；另测rc=0且成功/失败标记同时出现 → FAIL。
- 超时、异常、缺工具/依赖 → FAIL或NOT_RUN，整体不能PASS。
- 上次SIM目录存在、此次harness失败 → 后续不得使用旧目录判PASS。
- 多包混合成功/失败 → 整体非0，不因最后一包成功覆盖前一失败。
- --stage-upload → 无真实写入、无覆盖，明确拒绝。
- 测试全部使用临时合成小输入与mock；不得导入真实runner、torch模型或调用CUDA。不得把这些测试称为真实包前向/合规验收。
- Git差异只在允许范围；原外置脚本哈希、旧台账/包不变；不改既有暂存内容，不提交/推送。

可如实结项：权重来源无法闭合、没有可用的候选或发现更多问题，只要清单保留UNKNOWN与证据，门禁修复满足判据。禁止为“完成”伪造链路或修改判据。
