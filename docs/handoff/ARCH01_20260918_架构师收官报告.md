## 2. 关键诊断：分数由**速度项**驱动，质量代理对本模型族不敏感（本轮新能力）

- 环境已具备 `pyiqa`（0.1.16）与网络/权重缓存，可本地复算官方风格的 NR 指标：**CLIPIQA / MUSIQ / MANIQA / NIQE**（历史 M24 runner 明确记载官方质量评测用 pyiqa 这一组指标）。
- **全量 100 图对照**（A2 vs OPT-01，逐图同指标）：clipiqa 均值相对变化 **−0.009%**、maniqa **−0.019%**、niqe **−0.003%**，各指标约 45–55/100 张互有胜负 → **两者质量在代理上不可区分**。
- 推论（区间推断）：A2→OPT-01 的 +2.84 分来自**速度项**；而质量项对「跨精度/融合级」这类细微改动几乎不敏感（改动涉及 12–23% 像素、≤11 级），本模型族的 NR 质量基本处于平台期。
- 官方换算高度压缩：512 速度提升 1.49×（4K 生产 1.73×）仅换来总分 +6.72% ⇒ **每 10% 时延约 +0.4~0.5% 总分**，微优化的边际收益极小。

### 3.1 为什么停止这条线

1. 剩余**安全**收益 ≤2%（≈+0.2~0.3% 总分），已在官方分差噪声量级；
2. 唯一 ~10% 量级的杠杆（executor）在「首调被计时」或「按调用均值计分」的协议下会把速度分**打回甚至打崩**，且机制细节未完全解释——不符合「可解释才交付」的标准；
3. 上一轮已证明：跨精度改动能带来 +6.72%，而那类改动（改数值路线）现在已无更多空间（DiT/DINO 已是 fp16，VAE 已 fp16）。
