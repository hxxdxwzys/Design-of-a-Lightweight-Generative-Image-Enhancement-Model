| 变更 | 时延 | 质量代理 | 官方分 | 推断 |

- 结论 A：**质量与速度都是真实项**；本轮两条杠杆都已单独验证并各自带来正收益。

| 路线 | 预期 | 实测/阻断 |

## 3. 当前封顶估计与依据

- 合规同主体路线（同一父资产 + 自有 JIT 包 + 同主体 100 图）在现有资产与 8 GB 笔记本 GPU 上的封顶约 **46–50**：质量端已被代理证明在平台期（NR 四指标对小改动的响应上限约 ±8%），速度端已把可做的执行层优化测尽（executor +9~12% 但加载 +32 s/首调 5 s，判为协议风险；双流 0%；cuDNN autotune −0.8%）。
- 排行榜 99–217 的量级与历史记录（解耦组合 94/105 =「M24 图 + 快速测速件」）一致：**高分主要来自「质量件与测速件不同主体」的组合**，该做法在本项目 D17/D18 下被否决；本 Agent 不会在未获用户明确授权与规则确认前采用。

## 4. 需要用户资源或授权的选项（按性价比排序）

1. **算力/数据投入**（最高上限）：借/租一台 ≥24 GB 显存机器，或允许下载训练数据 → 可跑 1.4B 或多步教师，或做一次真正的 LoRA/蒸馏训练。需要：机器、时间（≥1–2 天）、磁盘/带宽。
2. **规则澄清**：请用户向主办方确认「质量件与测速件是否必须同主体、是否允许量化/int8、是否允许 IQA 目标训练」；澄清后本 Agent 可据此选择被阻断的路线（这属于外部信息，只能由用户提供）。
3. **继续微增**（无需新资源，收益 ~+0.5–1.5%/次）：例如更强但仍有代理支撑的后处理组合；已被本次扫描证明空间有限（unsharp 强度扫描中 p60 已是最优点，p100/p140 的 clipiqa 更差）。
