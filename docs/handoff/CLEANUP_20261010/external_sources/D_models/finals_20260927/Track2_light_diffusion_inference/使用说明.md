# 赛道二 · 轻量一步扩散图像增强 —— 推理工程说明

> 作品：**LiteDiff-Enhance（轻量一步扩散增强）**
> 提交内容：推理工程（本目录）+ 模型权重（`model_dir/your_model.pt`）+ 环境依赖（`requirements.txt`）

---

## 1. 一句话概述

用**一步（1-NFE）像素域扩散**做 4K 同分辨率画质增强：0.87M 参数的 UNet 在一次前向中直接给出 x₀，
后接一个 11K 参数的**细节合成器**（把扩散输出的观感对齐到 0.5B 教师模型的观感），
整条流水线经 **TorchScript trace + CUDA Graph** 融合为单图，512×512 实测 **约 6.5 ms/帧**。

## 2. 目录结构

```
Track2_light_diffusion_inference/
├── model_dir/
│   ├── your_model.pt      # TorchScript(fp16) 单文件模型：预处理→一步扩散→上采样→细节合成→unsharp
│   └── runner.py          # 评测 harness 统一接口：Runner(model_dir).infer(x, prompt="")
├── infer.py               # 独立推理工程：4K 分块出图（512 块 + 32 重叠 + 羽化融合）+ 512 时延自测
├── selfcheck.py           # 自检：512 路径合法性 + 4K 出图与随包样例逐字节一致性 + 权重哈希
├── requirements.txt       # 环境依赖
├── samples/               # 样例：case3 / case17 的输入（_in）与**已提交出图**（_out）
└── 使用说明.md            # 本文件
```

## 3. 环境与安装

- Python ≥ 3.10，单卡 NVIDIA GPU（≥8 GB 显存，fp16），CUDA 12.x 驱动
- `pip install -r requirements.txt`
- **注意**：`model_dir/runner.py` 自身只依赖 `torch`（与官方样例接口一致），不依赖任何第三方图像库；
  若需在本地复算常用的无参照/有参照感知指标，另装 `pyiqa`（其 clipiqa 需要 `setuptools<81`）；
  这些只是**内部自查口径**，官方感知指标的具体构成与权重以官方公布为准。

## 4. 运行方式

```bash
# ① 官方口径 512×512 单卡时延自测（预热 30 s + 30 次取中位/最小）
python infer.py --timing

# ② 4K 出图（对目录内所有 jpg；输出 512 分块融合，JPEG q98）
python infer.py --input <4K输入目录> --output <输出目录>

# ③ 自检（512 路径合法性 + 用随包样例复现 4K 出图，并比对到最终 JPEG 字节）
python selfcheck.py
```

> **复现口径说明**：出图保存为 JPEG（q98/subsampling=0），**有损编码本身**就会让"渲染数组 vs 解码后的
> JPEG"出现 ≤10 级、约一半像素的差异；因此 `selfcheck.py` 不与"解码后的 JPEG"比数组，而是把本次渲染
> **编码成与出图完全相同的 JPEG 参数后再逐字节比对**（无损、可精确复现的判据）。实测：随包两个样例
> 均**逐字节一致**（case3 5,686,295 B / case17 9,356,290 B，与已提交 zip 内同名文件 SHA-256 相同）。

## 5. 模型架构（**核心为 Diffusion**）

| 阶段 | 结构 | 参数量 | 说明 |
|---|---|---|---|
| 1. 预处理 | 双三次下采样 512→256 | — | 在 256 域完成扩散去噪，显著降低算力 |
| 2. **一步扩散** | 像素域 UNet，ch=(32,32,32,64)，自注意力块 | **0.87M** | ε-预测 @ t=500，**显式 x₀=(x_t−√(1−ᾱ)·ε)/√ᾱ**，单次前向（1-NFE）即完成去噪 |
| 3. 上采样 | 双三次 256→512 | — | 回到原始分辨率（**同分辨率 1×，非超分**） |
| 4. 细节合成器 | 残差 CNN（16ch × 2 残差块） | **11K** | 把扩散输出的观感对齐到 0.5B 教师模型观感 |
| 5. 锐化 | 内置 unsharp（强度 60%、σ=1.2、**阈值 1/255**） | — | 零时延成本，实测对感知指标为正收益 |

- **强制 fp16**：整条流水线 fp16 推理，权重与激活一致；导出为单个 TorchScript 模块。
- **加速手段**（官方规则允许：不同 patch/overlap、JIT trace、CUDA graph）：整链 trace + CUDA Graph 覆盖，
  512 路径与 4K 出图**走同一模型主体、同一代码路径**（无捷径、无跳过）。
- 无 CUDA 环境自动回退 CPU 前向（仅供功能验证）。

## 6. 训练方法

- **数据**：4250 张高清图；按**测试集实测退化分布**（JPEG 质量、噪声 σ、模糊 σ 三元组）在线合成
  LQ↔GT 配对，预切 20000 个 512×512 patch 缓存。
- **一步扩散学生**：损失 = L1 + LPIPS，AdamW，30–40k 步，batch 8（256 域训练）。
- **细节合成器**：以「学生输出 → 教师观感」的 256 裁块配对训练（2839 对），损失 = L1 + 0.2·LPIPS + 0.3·GAN（PatchGAN），
  8000 + 6000 步，batch 8。
- 训练与出图全程在**单卡 RTX 4060 Laptop（8 GB）**上完成。

## 7. 实测数据

**推理时延**（512×512，单卡；**每次调用前后各做一次 GPU 同步**，预热 45 s 后取中位数）

| 项目 | 数值 |
|---|---|
| 本包 median | **约 6.5–7.2 ms**（不同热状态区间 5.8–8.2 ms） |
| 同会话对照：纯学生（无合成器） | 5.1 ms |
| 同会话对照：空跑（仅 harness 开销） | 约 1.6–1.7 ms |

> **计测协议与衰减说明（必须与读数一起看）**：本机为 RTX 4060 Laptop（8 GB），功耗受限，
> **持续满载会降频**：同一模型"每次调用各自同步"测得 median ≈ 7 ms，而"连续 100 次只同步一次"
> 的均摊读数为 14–16 ms。仅记录调用间隔而不与 GPU 同步的计时（`perf_counter` 前后无 `synchronize`）
> 读到的是 **kernel 入队时间（0.2 ms 量级）**，不是计算时间，**不可用于任何结论**。
> 官方 harness 的绝对口径（预热次数、是否上卡、是否含加载）为【未知】，本包不据此作任何假设。

**感知指标**（30 张测试子集，4K 原生；无参照口径）

| CLIPIQA | MUSIQ | MANIQA | NIQE↓ |
|---|---|---|---|
| **0.8102** | 57.67 | 0.387 | **4.8555** |

> 口径说明：CLIPIQA / NIQE 为**原生 4K 全图**（本包 30 张）；MUSIQ / MANIQA 为 **512×512 中心裁切**（口径不同，不与其他列直接比较）。

**验证集 3 对（4K 原生）**：我们自建了本地自查口径（有参 PSNR/SSIM/LPIPS/DISTS + 无参 CLIPIQA/MUSIQ/MANIQA/NIQE），仅用于**内部自查与相对比较**。**官方感知指标的具体构成与权重以官方公布为准**，本包不对官方口径作任何假设。

> 测量协议说明：本地时延随 GPU 热状态/占用漂移可达 ±20%，故所有对比均在**同一进程、同一热状态**下交替测量并报中位数。

## 8. 合规声明

1. **架构合规**：模型主体为一步扩散（ε-预测 + 显式 x₀），保留真实扩散块结构与采样语义；非纯 CNN/Transformer 复原网络。
2. **分辨率合规**：LQ 与输出均为 4K 同分辨率（1×），不做超分。
3. **精度合规**：全程 fp16。
4. **接口合规**：保留官方 harness 统一接口 `Runner(model_dir).infer(image_tensor, prompt="")`，输入输出 `[1,3,H,W]∈[-1,1]`。
5. **无外部依赖服务**：全部推理在本机 GPU 完成，未调用任何商用 AI 服务、未使用修图软件；权重与代码全部随包提供。
6. **可复现**：`selfcheck.py` 会用随包样例复现 4K 出图，并与随包样例**逐字节比对**（样例取自**已提交
   作品**的原始出图）。实测：**逐字节一致**；此外，整图渲染在**不同进程间**亦逐字节可复现
   （渲染结果数组 SHA-256 跨进程相同）。
