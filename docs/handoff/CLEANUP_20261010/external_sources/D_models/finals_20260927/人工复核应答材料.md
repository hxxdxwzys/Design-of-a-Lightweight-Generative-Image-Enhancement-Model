## 六、如实披露（不隐藏）

1. **本地时延测量曾存在缺陷**：修正前未做 GPU 同步，会读到 kernel 入队时间（min 0.05 ms，物理不可能）。**已修正**为每次调用前后 `torch.cuda.synchronize()`，修正后 median 6.5–7.4 ms。
2. **本机为笔记本 GPU、功耗受限**：持续满载会降频，"连续 100 次只同步一次"的均摊读数约 10–15 ms，**高于**单次同步读数。两者我们均如实报告。
3. **有参照保真（PSNR）低于输入**：这是感知增强任务的固有取舍；我们不声称全面占优，并公开双轴完整实测。
4. **本作品相对我们上一次成功提交件的改动**：仅把内置 unsharp 的**阈值 3/255 改为 1/255**（其余逐项不变）。本地同链实测：clipiqa 0.8042 → **0.8102**、niqe 4.9967 → **4.8555**，配对符号检验 n=30 分别为 29/30 与 28/30 胜（p<0.0001），**512 时延无变化**。
5. **官方感知指标的具体构成与权重我们不知道**（官方原文：决赛入围名单时公布）。我们**刻意不针对任何猜测的口径做定向优化**。
