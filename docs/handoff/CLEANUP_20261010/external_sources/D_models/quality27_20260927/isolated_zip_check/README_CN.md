# TinyRef V4t1 EdgeFix 赛后工程修订版

## 使用前必须了解

此包与初赛V3得分原件不是同一版本。V3的官方成绩不能赋给本包。组委会是否接受赛后修改尚未明确；若只允许复现初赛得分件，应使用另行保留的V3正式复核包。

本包保留V4t1权重和runner的原始字节，只修复外部出图程序：图像最外侧融合权重从0改为1，重叠内部继续羽化，融合后以最近整数恢复8位色阶。不使用修图软件、商业图像生成服务、图像检索或参考输出替换模型推理。

FACT：修正了零权重强制黑边和浮点直接截断的误差。UNKNOWN：整体主观画质/官方成绩是否提高。本次没有获得更强的新权重。原图条件细化器训练在完整验证上未通过，未纳入本包。

## 模型与图像关系

模型为876,662参数的一步扩散UNet及残差细化CNN，权重fp16。512输入下采样256，t=500预测噪声、一步去噪，再上采样512、细化、内置锐化和8位网格输出。V4t1锐化阈值保持1/255（输入归一化域为2/255），没有更改。

`model_dir/runner.py`加载整个TorchScript。CUDA可用时使用完整链CUDA Graph。4K以512块、32重叠逐块调用相同的`Runner.infer`，512测速接口没有另一套小模型或特殊旁路。4096×3072输入63块。包内两个样例均由本包模型、runner和infer.py生成，身份绑定见generation_manifest.json。

## 环境与命令

声明支持记录中的CUDA环境，不支持CPU前向。TorchScript继承固定CUDA设备常量，CPU能加载不代表能推理。

Python3.13、torch2.7.0+cu126、numpy2.4.6、Pillow12.3.0为本地已验证版本。新环境可按requirements安装兼容依赖，需兼容CUDA12.6的NVIDIA驱动；其他环境的字节一致性未验证。本轮未安装依赖。

在工程根目录执行（使用`-B`避免生成不在身份清单内的缓存）：

```text
python -B selfcheck.py
python -B test_edge.py
python -B infer.py --modeldir model_dir --input INPUT_DIRECTORY --output NEW_OUTPUT_DIRECTORY
```

输入为RGB图像或JPEG目录，两个维度均至少512，输出保持原分辨率。输出目录请放在工程外，程序拒绝覆盖已有结果。推理前验证全包文件及模型固定指纹，不读取样例参考输出。

复现样例时，将samples/case3_in.jpg或case17_in.jpg作为输入，在新目录得到同名输出，再与samples/case3_out.jpg或case17_out.jpg比较。本地两独立进程已经完成这两个完整4K样例的JPEG字节一致性验证，证据随包提供。

## 证据范围和限制

- 两个样例的全图生成和独立复现通过，不代表其余98图已重新出图。
- 原黑边证据在JPEG编码前检查。修复后最外圈不再强制全黑；真实黑色内容仍可为黑色。
- 编码前、排除外缘16像素带，修复与同一模型块的旧融合方式最大差不超过1个色阶。JPEG重编码可改变更多像素，不能把此界限套到JPEG解码差异上。
- 本包属于可审查工程修订，不是原件逐字节复现，也不宣称获得组委会合规或换件许可。
- 完整训练数据授权与历史教师/父模型谱系不由本次边缘修复验证解决。历史存在IQA训练探索的事实未被本包撤销或隐藏；本包没有新增此类训练。
