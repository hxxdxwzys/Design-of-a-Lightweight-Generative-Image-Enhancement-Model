# V3一页方案简介内容稿（非PPT交付物）

## 页面标题

TinyRef V3：轻量一步扩散图像增强

## 方案说明

用于4K同分辨率增强。512图块下采样至256，经t=500的UNet噪声预测和一步去噪，再上采样、细化与锐化。

## 模型与部署

总参数876,662，UNet占871,139，细化CNN占5,523。
原模型为fp16权重的TorchScript，原runner在CUDA支持时使用CUDA Graph。
4K采用512窗口、32重叠与羽化融合，4096×3072对应63块。各块与512接口调用同一模型。

## 原件复核

本材料对应Track2_TinyRefV3.zip。模型和runner保持原件字节不变。
case3与case17参考图直接取自V3原包，以JPEG字节和解码像素分层核验。
复现实测结果：两个独立进程各重生成case3、case17，两张图在两个进程均与原JPEG逐字节一致，解码像素差为0。仅限所测两样例和当前CUDA环境，不外推100张或官方环境。
