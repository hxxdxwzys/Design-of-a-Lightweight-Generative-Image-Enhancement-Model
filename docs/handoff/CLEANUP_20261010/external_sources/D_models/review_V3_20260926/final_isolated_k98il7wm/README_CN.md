# TinyRef V3 初赛复核工程

## 版本与用途

本工程复核 `Track2_TinyRefV3.zip`，不以初赛结束后改进的 V4t1 替换初赛原件。

- FACT（用户提供）：V3 在初赛官方评测获得约70分。
- FACT（仓库历史记录）：精确分数登记为70.1021。平台提交编号和成绩截图未随本工程取得，最终对应关系以平台记录为准。
- FACT（文件核验）：模型与 runner 从 V3 原ZIP逐字节提取，指纹见 `manifest.json`。
- 本工程为复核时重新整理的便携入口和验证工具，不将这些新增文件冒充为初赛提交时已有文件。
- UNKNOWN：组委会是否允许以初赛结束后改进版本替代原得分版本。V4t1不包含在本工程中，其官方得分未知。

## 内容

`model_dir/your_model.pt` 与 `model_dir/runner.py` 为原件。`infer.py` 为历史出图逻辑的便携整理，`selfcheck.py` 和 `verify_reproduction.py` 为新增严格验证工具。`samples/` 中输入来自官方测试集，两个参考输出直接来自 V3 原ZIP，不是此次重新生成的参考答案。

`manifest.json` 绑定原ZIP、包内文件及样例来源。`original_members.json` 列出原ZIP全部102个文件的字节数和SHA-256，包括100张历史结果图；这份事后盘点不是初赛生成时的manifest。

## 实际推理结构

512输入先双三次下采样至256。UNet在t=500预测噪声，以显式一步去噪公式得到复原结果，再双三次上采样、经过细化CNN和内置锐化、8位网格处理。

模型参数总数876,662，其中UNet 871,139，细化器5,523。细化器为4个卷积层及外部残差连接。权重为fp16，不宣称所有临时计算与输出张量均为fp16。

4K出图在外部按512窗口、32重叠、羽化融合处理，同一 `Runner.infer` 执行每个块。4096×3072或3072×4096各63块。局部分块不等于完整4K全局上下文。512接口与4K分块调用同一原模型，不使用样例查询或输出缓存。

## 环境

只声明CUDA推理，不能以模型能在CPU加载推导CPU前向可用。原TorchScript含固定CUDA设备常量。当前复核环境及运行开关见 `environment.json` 和复现报告。

当前依赖固定在 `requirements.txt`。新环境可执行：

```text
python -m pip install -r requirements.txt
```

需要兼容CUDA 12.6的NVIDIA驱动。此次没有执行依赖安装，不保证另一操作系统、显卡、驱动或JPEG库下字节级一致。环境兼容失败须如实报告，不能放宽精确复现标准后仍宣称精确通过。

## 使用

先核验身份（不使用GPU）：

```text
python -B selfcheck.py --identity-only
```

对新输入目录推理（两边长至少512；不覆盖已有输出）：

```text
python -B infer.py --input INPUT_DIRECTORY --output NEW_OUTPUT_DIRECTORY
```

严格复现原样例（输出目录须为工程外的新目录，同一时刻不得运行另一个GPU任务）：

```text
python -B verify_reproduction.py --output NEW_EVIDENCE_DIRECTORY
```

两独立进程分别执行一次512接口检查和case3、case17的完整分块推理。全批最多300次预留调用、900秒，包含原runner构造期3次预热和1次CUDA Graph捕获的保守预留。失败也计入，不自动重试。监督进程超时终止工作进程树。遗留锁需先核实进程状态，不得直接绕过。
