# 决赛问题清单（2026-08-31，待用户发到天池讨论区）

> 目的：这些答案决定决赛打法（275.90 对手是否现场可跑、评分口径、我们的 runner 形态）。
> 建议以"参赛选手"身份在赛题讨论区发帖，问题合并精简为 3-5 条。

## 必问（按优先级）

1. **决赛现场 20 张图的评测方式**：
   - 是现场跑各队提交的 model_dir（用我们的 runner.py），还是各队自带环境/自带电脑现场处理？
   - 现场提供什么 GPU？（型号/显存）——这决定 275.90 式大模型的可行性，也决定我们 runner 的优化目标。

2. **决赛评分公式**：
   - 赛题说"具体计算指标方法在决赛入围名单时公布"——能否提前公布（或说明初赛/决赛是否同一公式）？
   - 决赛的"现场测试计算分数"是否包含推理时延加速比？若包含，用什么基准与输入规格（512×512？）？

3. **初赛评分细节（若有窗口）**：
   - 有参考指标的 LPIPS 具体是哪个版本/骨干（alex/vgg）？评测分辨率是否原生 4K？
   - 综合分的归一化方式（相对 LQ 基线？GT 天花板？）

4. **TESTCASE 账号（189.98 分）的性质**：是否为官方测试账号/参考解？其分数是否可作 GT 天花板参考？（用于校准，可含蓄问"榜单上 TESTCASE 的评分口径"）

5. **提交次数**：赛题写"每周一次"，但实际可用 10 次——决赛前是否还有初赛提交机会？初赛截止时间？
