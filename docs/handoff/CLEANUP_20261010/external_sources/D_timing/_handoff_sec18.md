### 18.6 工程记录（今日踩的坑，全部已修）
1. **pyiqa 的 DISTS 要 [0,1] 输入**（lpips 包要 [-1,1]）→ 直接喂 [-1,1] 报 `Input must be normalized to [0,1]`。
2. **模块名遮蔽**：先 import 了 M24 包内 vendored `dinov2`，再让 torch.hub 载入真 dinov2 repo ⇒ `No module named dinov2.hub`。修：载入 PixRestore 前清空 `sys.modules` 里的 dinov2*，并**分进程跑**（pix 配置一个进程、包配置一个进程）。
3. **UNet2DModel 默认 norm_num_groups=32** ⇒ 通道数必须能被 32 整除，ch=16 直接报 `num_channels must be divisible by num_groups`（v9a 第一版 0.4 分钟即挂）。
4. **链内时延循环过慢**：xl10/l10 各跑 50 次迭代 = 20~40 分钟 → 改成自适应（先 3 次探测，再按 4 秒预算定迭代数）。
5. **渲染口径不一致**：`render_tiny.py --limit 30` 是**数值序** case1..case30，而 `measure_test30` 用**字典序**前 30（case1, case10, case100, case11…）⇒ 两者只有 27 张重合、数字不可比。已新增 `render_subset.py --order lex` 保证同口径。
6. `subprocess.run` 输出缓冲导致链日志要等子进程结束才落盘 → 中途看进度请看各脚本自己写的 JSON/日志（如 `sweep_val_fullref.json`）。
