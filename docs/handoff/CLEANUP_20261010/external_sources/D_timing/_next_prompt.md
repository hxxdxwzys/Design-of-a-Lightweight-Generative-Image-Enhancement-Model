## 5. ⭐ 当前第一优先：Q2 —— M24 runner 的**合法提速**（【实测】热点已定位）

%%BT%%q2_profile.py%%BT%% 的 op 级表（6 次 infer 合计）：

| 组件 | CUDA 时间 | 折合每次 | 说明 |
|---|---|---|---|
| conv2d（cudnn+cutlass） | 1.87 s | ~310 ms | **VAE 的活** |
| group_norm | 0.60 s | ~100 ms | 同上 |
| linear/addmm/bmm | 0.80 s | ~133 ms | 0.5B DiT 的活 |
| **to / copy_** | 0.54 s，**5124 次调用** | **~90 ms，854 次/次** | **dtype 搬运，明显浪费** |

- **结论：VAE（conv+groupnorm）比 0.5B DiT 还重**；另有巨量 fp16↔fp32 搬运。
- **合法手段**（规则明文：可不同 patch/overlap、JIT trace、CUDA graph）：CUDA Graph 固定 512 形状捕获 + 统一 dtype。
- **预测**：352.9 → 200~250 ms ⇒ r 0.81→1.2~1.4 ⇒ 合规分 **43.7 → 48~52**。
- **关键便利**：**图像可逐字节不变**（同权重、同 512 前向）⇒ 同主体零争议、**不占提交次数就能本地迭代**、**无需重渲 100 张**。
