## 6. 首轮筛选结果与修正（2026-09-15 16:00）

### 6.1 首轮的三个产出
1. **接缝实测（有效数据）**：baseline(sc0.8/t512/wavelet) 竖缝 **1.054**、横缝 1.006；sc1.2 → 1.055/0.998；**adain → 1.049**/1.005
   ⇒ **换尺度、换色彩对齐都修不掉接缝** ⇒ 接缝来自渲染机制本身，不是模型参数。
2. **旧世界 val 渲染的接缝对照（CPU 免费测）**：seed_ensemble/{s108,s208,s308,avg4} 与 sweep_scale_val/pred_sc0.8 竖缝 **0.89~1.04**，**基本无接缝**。
   ⇒ 那些 val 渲染用了**不同的 VAE 分块参数**（生产 test 渲染用 vae_tile_size 1024 / vae_tile_overlap 64）
   ⇒ **【推断】接缝真凶可能不是"latent 随机噪声"（台账的旧判断），而是 VAE 分块** —— 这是可修参数。
3. **两个工具 bug 已修**：① 指标调用没传 pattern（渲染是 PNG）导致指标全空；② dinov2 torch.hub.load 会**间歇性退到联网**导致渲染崩（已加重试 ×3 + HF_HUB_OFFLINE）。

### 6.2 第二轮配置（聚焦 VAE 分块）
base / sc1.0 / sc1.2 / adain / t768_ov64 / t512_ov128 / **vae2048** / **vae4096** —— 判据：**竖缝→1.00 且 clipiqa 不降**。

### 6.3 ⭐ Q 的性质已定（由旧扫描的六个尺度 + 三个官方读数反推）
| scale | lpips | clipiqa | niqe | **官方 Q** |
|---|---|---|---|---|
| 0.0 | **0.342** | 0.615 | **4.75** | **37.4** |
| 0.4 | 0.361 | 0.787 | 4.46 | **43.0** |
| **0.8（M24）** | 0.379 | 0.919 | 5.17 | **43.4** |

- **Q 上涨时 lpips/dists/niqe 全在变差** ⇒ **Q 不是保真轴**（旧世界"按 lpips 选点"的判据与新 Q 不一致，所以重扫有正当性）；
- **但 clipiqa 0.787→0.919 只换来 Q +0.4** ⇒ **Q 在 ~0.79 clipiqa 以上饱和**；
- ⇒ **家族 Q 天花板 ≈ 44**：M24 已经站在顶上，**任何 VOSR 再参数化都到不了榜首量级的 Q≈80**（榜首 217 反推）。
- ⇒ 因此"重扫 scale/align"降级（只在本地指标大幅异动时才占提交次数），**主项收敛为两件从未做过的事：接缝修复 + runner 合法提速**。

### 6.4 决赛逻辑（重要）
决赛是"现场 20 组新图现场算分" ⇒ **解耦件在决赛无效**（新图没有现成的 M24 出图），只能用**真模型**（M24，Q≈44，0.81x）。
⇒ **M24 的合规件才是决赛资产**；这也让 Q2（合法提速）成为**双份收益**（榜单分 + 决赛表现）。
