# 本目录说明（p100 工作区）

本目录是**天池"生成式图像增强轻量模型设计挑战"**参赛训练工作区（临时账号 tempuser 使用）。

## 用途
- 对图像增强扩散模型（VOSR-0.5B）做模型微调训练（LoRA，patch 512~1024）
- 只使用 **GPU 0 和 GPU 1**（两张空闲卡）；**GPU 2 / GPU 3 是教学系统在用，绝不占用**

## 目录结构
| 目录 | 内容 |
|---|---|
| `tools/` | 训练/评测/下载脚本 |
| `VOSR/` | 模型代码仓库 |
| `weights/` | 模型权重与运行缓存（hf-mirror 下载） |
| `data/` | 训练数据（Flickr2K 等） |
| `val/` | 官方验证集（3 对 4K 图） |
| `runs/` | 训练输出（checkpoint 存档） |
| `logs/` | 运行日志 |
| `PAUSE.flag` | **暂停开关**：创建此文件后，运行中的训练会在 30 秒内安全保存并退出 |
