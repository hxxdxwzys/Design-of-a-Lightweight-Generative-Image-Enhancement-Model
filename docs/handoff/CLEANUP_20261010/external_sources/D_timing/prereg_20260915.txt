=== 预登记 (2026-09-15, 链 C/D 结果出来之前写下) ===

【背景事实, 非推断】
1. TinyV7gan 官方 41.7346; TinyV5d 官方 33.0382。同架构(0.87M)/同 256 域/同数据/同速度档(4.62 vs 4.65 ms)
   => +8.70 全部来自图像侧。主线差异: v7gan 加了 0.1·LSGAN PatchGAN 对抗损失。
2. M24(官方基准 43.6951) 在本地四项有参指标上全部差于"什么都不做"的 LQ:
   LQ 23.897/0.9246/0.4977/0.3139 vs M24 22.480/0.8966/0.4476/0.3642 (val 512 中心裁切)。
   => 官方质量项不可能以有参为唯一主导(否则一个四项全差于 LQ 的模型不会拿到 43.7)。

【链 C 的判别性读数 (预登记)】
A. 若 pkgv7 的有参四项明显优于 pkgv5 => 对抗纹理的 +8.70 与"更接近真值"一致
   => 目标应转向"保真 + 纹理"(1x 分辨率的 v9a 正对症)。
B. 若 pkgv7 的有参四项与 pkgv5 相当或更差 => +8.70 是"观感/无参"效应
   => 目标应转向"更强的对抗纹理生成"(加宽/加强 GAN), 而不是分辨率。
C. 若 HYPIR 出图的 test30 clipiqa 显著高于 M24(0.9023)/v7gan(0.5059) => HYPIR 观感值得蒸馏。
D. v7gan 轨迹 (8k/16k/25k): 若 clipiqa 随步数单调上升且 25k 未饱和 => "训练更久"是免费杠杆。

【链 D (v9a = 512 域, ch 16,16,16,32, GAN, 25k 步) 的判据 — 提交与否】
- 动机(假设): 256 域把 512 输入降采样 2x, 学生看不到高频, 只能幻觉; 官方 LQ 本身只轻退化。
  v9a 把输入分辨率改回 1x, 且通道数降到 1/4 使算力(=>速度)与 v7gan 相同 => 干净的"分辨率"单变量。
- **提交条件(必须同时满足)**: ① 空闲 512 时延 <= 6.0 ms (>= ~48x)
  ② test30 clipiqa >= 0.52 (v7gan 0.5059) 或 val LPIPS <= 0.42 且 DISTS <= 0.29
  ③ 门禁全过 (含 IFACE: 真实图 std > 0.05)
- **不提交条件**: clipiqa < 0.45 (说明容量而非分辨率是瓶颈) => 改为在 512 域加容量 (0.87M@512, ~15x)。
- 不允许: 为了让数字好看而调低/调高任何指标口径; 不允许用未验证的代理否决一个"新格子"。
