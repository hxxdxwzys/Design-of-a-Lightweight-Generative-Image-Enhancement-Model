=== PixB 出分后的行动规划（预登记，2026-09-15，在分数出来之前写下）===

【PixB 是什么】PixRestore-b 单步（像素空间流匹配 DiT + DINOv2-B 条件，403MB），家族外资产。
  同口径实测：val PSNR 23.707 / SSIM 0.9199 / LPIPS 0.4109 / DISTS 0.2907 —— 四项里除 LPIPS 外全家族最好；
  512 时延 155.9~199.4 ms（1.4~1.8x）；观感代理 test30 clipiqa 0.3143（≈ LQ 0.2752 档，远低于 M24 0.9023、v7gan 0.5059）。
  对照：M24 = 四项有参全劣于 LQ，官方 43.6951；v7gan = 60x 档观感最好的学生，官方 41.7346。

【判据与规划（四分支）】

■ 分支 1：PixB > 43.7（超过我方最佳）
  => 说明"有参保真"在正式评分里权重很大，我 9/15 的"官方质量项≈观感"结论被推翻（要如实记录并改写台账）。
  动作（按优先级）：
   1) 立刻跑 PixRestore-l @1 步（LPIPS 0.3874 全场最好；代价 0.53x）与 s @1 步（3.2x）的 test30 观感 + val 四项，
      若 l 的观感不塌 => 下一发交 l（新格子）；
   2) 同时做"把 PixB 观感蒸到 60x 学生"：用 gen_distill_data.py 的同一管线，教师换成 pkg_PixB 的 runner，
      生成 2000 对 512 patch（~10 min GPU），再训 0.87M/256 域 GAN 学生（~2h）=> 若成立就是"保真=教师 + 速度=60x"的最优组合；
   3) HYPIR 合规 runner 升级为 P1（它的 DISTS 0.2633 也是全场最好），与 PixB 组成"保真双源"。

■ 分支 2：30 < PixB <= 43（有参有效但不足；按现状最可能落在 33~40）
  => 保真与观感都要，但观感更贵。动作：
   1) 仍做 1) 的 PixB-look 60x 学生（成本 2h），因为"教师更好"已被 v5d->v7gan 的 +8.70 证明是活杠杆；
      判据：学生的 test30 clipiqa >= 0.52 且空闲 >= 50x => 交一发；
   2) 与正在跑的 v9b/v9a（512 域分辨率线）并列比较，谁在"观感×速度"上更优就交谁；
   3) 不做 PixB 的 l/xl/多步重出图（本地已证伪：多步三项有参更差、时延 7.8x）。

■ 分支 3：PixB ≈ 30 或更低
  => 观感轴主导确认，保真几乎不加分（PixB 比 M24 还快、四项有参还更好却拿不到分）。动作：
   1) PixRestore 家族**不再投入**（l/xl/10 步一律不试，避免重复格子）；
   2) 全部火力留在"高倍速 + GAN 观感"这条线上（v9b/v9a/v8s => 加宽/加强对抗/更长训练）；
   3) 唯一保留的用法：把 PixB 当**纹理/细节教师**做一次消融（学生目标 = 0.5*PixB + 0.5*M24 观感），
      如果比纯 M24 教师好 => 说明"更保真的纹理"仍有价值，反之彻底关闭这条线。

■ 分支 4：测速失败 / 测评失败（IFACE 风险：随机张量输入时输出 std≈0.027）
  => 不计提交次数，只是损失一天。动作：
   1) 不要在 runner 里做任何"针对随机输入的特殊分支"（那是测速套利，红线）；
   2) 正当做法：给 runner 加**残差/跳连**（y = a*model_out + (1-a)*lq，a≈0.9）并**重出 100 张图**，
      同一主体、真实前向、对真图影响极小，但对 OOD 输入输出 std 有下界；
   3) 或改用"同一主体的 60x 学生"出图+测速（若分支 1/2 的蒸馏学生已经更强）。
