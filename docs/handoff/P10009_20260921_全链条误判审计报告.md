## 二、被证实的结论

1. **乘法结构 + p≈0.19**（E1）：M24 同一批图在 1.60 ms ↔ 2929 ms（1800×）之间反解 IT 稳定在 43.6~44.2（±1.4%）；6 组两两标定 p = 0.179~0.202。加法结构被否（同图反解 IT 36.6~88.1）。
2. **分数尺度未变**（E2b）：用旧时代曲线预测新时代 5 点，隐含尺度 s = **1.007 ± 0.068**（clipiqa）⇒ 9/19「<50」与 9/20「66~70」同尺，差异由模型不同 + 15% 级误差解释。
3. **提交件与 runner 完全同源**（E3）：对 V3 / V4 / V4us0 各重渲染全部 100 张 4K 图，与提交 zip 内图 **100/100 逐字节一致**；同输入重复推理 **逐位一致**。
4. **测量协议必须固定热态**（E4）：同包时延受 GPU 冷热/并发影响达 **±40%**（冷态首测 6.66~9.13 ms vs 热态 5.48~6.65 ms；并发 17.07 ms）；协议：先热机 ≥30~60 s，再在独立进程内 2 预热 + 20 计时，报 median 与 min。

## 三、修正后的分数模型（取代此前所有版本）

- **速度项**：`factor = (r/0.78)^0.19`，`r = 285.6/(t_ms + 2)`（不变，证据最硬）
- **图像项（综合代理）**：`IT ≈ 0.0447 · clipiqa^0.247 · musiq^1.661`（14 点，**R²=0.943**，残差多在 ±10%）
  ⇒ **musiq 的权重约为 clipiqa 的 6.7 倍**；niqe 几乎无预测力（残差 47.7%）
