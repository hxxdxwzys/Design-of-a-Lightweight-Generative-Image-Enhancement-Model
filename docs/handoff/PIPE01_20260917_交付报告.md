## 8. JIT 导出静态障碍清单（**未执行任何导出**，仅代码审阅）

1. peft LoRA 包装：LoraLayer 含数据依赖分支；script 前需 merge_and_unload，而合并会改变
   “可追踪 LoRA/scale”证据链，须另立任务并保留转换记录与等价性验证（D18 §3）。
2. model.forward = model.forward_flexible 为实例属性赋值；trace 可追踪、script 不接受；
   签名含 z_fea: list[Tensor]（DINO 多层特征），需显式类型与固定层数。
3. DINO 条件编码器来自 torch.hub 的 dinov2：forward_with_features 是运行期挂载的 MethodType，
   内部含 isinstance(x, list) 分支与 xFormers 缺失分支，不适合脚本化。
4. diffusers AutoencoderKL 与 latent_dist.mode()（DiagonalGaussianDistribution）不是 scriptable 类型；
   from_pretrained 加载路径也不能进图。
5. 分块管线是 Python 控制流（变长 tile 网格、逐块累积），脚本化需固定网格或把网格作为输入张量。
6. wavelet 后处理依赖 numpy + cv2.GaussianBlur + PIL，**不能进 TorchScript**，只能留在 Python runner 侧；
   your_model.pt 内不能包含它。
7. 随机 z 在核心内生成：trace 会固化当时采样；script 需显式传入噪声，而 TorchScript 不支持
   torch.Generator 作为输入。
8. 动态 H/W：harness 需 512×512，研究入口还要 4K；trace 固定 shape，至少需要脚本化 + 显式 tile 参数，
   或导出“单块子模型 + Python 侧编排”。
9. 需先确定导出粒度（整链 vs 仅 DiT）与等价性验证方法，再谈 JIT 交付；本轮 eager 实现不宣称交付格式通过。
