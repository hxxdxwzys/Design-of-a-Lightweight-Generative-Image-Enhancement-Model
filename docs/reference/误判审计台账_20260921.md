## E1/E2 实验结果（2026-09-21，回填）

### E1（分数模型全量重拟，n=18）

- **乘法结构成立**：M24 的同一批图在 1.60 ms ↔ 2929 ms（1800×）之间，反解 IT 稳定在 **43.6~44.2（±1.4%）**；6 组两两标定速度指数 **p = 0.179~0.202（均值 0.192）**。
- **叠加结构（加法）被否**：同一批图在加法模型下反解 IT 变化 36.6~88.1 ✗。
- **"质量已饱和"不成立**：同 clipiqa 下不同家族 IT 差近 2 倍（旧 tiny A=25.6 vs 旧 m24 A=49.2）；各子集斜率 0.184~0.483（R² 0.50~0.96）⇒ 单变量 clipiqa 不足以解释官方 IT。

### E2（全套代理回归，14 点：旧 9 + 新 5）

- **最优单代理 = musiq**：统一尺度下对数残差占总方差 **6.1%**（clipiqa 9.4%、maniqa 11.5%、lapvar 23.7%、**niqe 47.7%**）；旧时代子集 musiq 幂律 **R²=0.976**（clipiqa 0.880 / niqe 0.593）。
- **尺度一致性**：用旧时代曲线预测新时代 5 点，隐含尺度 s（clipiqa）= **1.007 ± 0.068**（CV 6.8%）⇒ **平台分数尺度未变**，"9/19 <50 vs 9/20 66~70"可由模型差异 + 15% 级误差解释。
- **对本族的关键读法**：refiner 把 clipiqa +27% 但只把 **musiq +15%**（48.6 → 53~58），而 VOSR/OPT10 的 musiq 为 **62.8 / 65.9** ⇒ **官方 IT 的高档由 musiq≈63+ 决定，那正是快线与 VOSR 线之间的 27% 差距所在**。
- **修正结论**：此前的"质量项饱和"应改写为"**clipiqa 饱和、musiq 仍有 15~20% 空间**"；主攻方向从 clipiqa 改为 **musiq/maniqa**。

### E10（代理口径自检）—— 发现重大口径差

- 动机：我们一直用 **512 中心裁切**测 musiq/maniqa，而官方在 **4K 全图**上算分。
- 实测（V4 提交件 case1，n=1）：musiq **4K=43.38 vs crop=61.73（crop 高 42%）**；maniqa 4K=0.4101 vs crop=0.2872（crop 低 30%）。单张耗时：musiq@4K **290 s**、@crop 0.4 s。
- ⇒ **绝对 musiq 数值依赖口径，不可跨口径比较**；我们此前的回归是在**统一 crop 口径**下做的（相对序关系与 R²=0.943 仍有效），但"musiq 58 vs VOSR 65.9"这类跨口径论断需重述为"同口径下 VOSR 高 8 点"。
- ⇒ 协议修正：**关键候选须补测 4K 口径 musiq（≥3 张）**；日常筛选用 crop 口径（快 700 倍）并只做**相对**比较。待办：E10b = 对前 3 名候选补 4K-musiq（各 3 张，约 15 min/候选）。

### E11（refiner 作用在 VOSR 出图上）—— 定位瓶颈

- 做法：把 V4 的 refiner（16ch/2bl，训练于"学生输出→M24 观感"）直接作用在 **OPT-10/VOSR 的 4K 出图**上（逐 512 块 + 羽化），测代理。
